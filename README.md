# Nomad Trails — Assignment #3

Responsive Web Design using **CSS Media Queries + Bootstrap 5.3**.

## Project topic
Nomad Trails is a fictional Kazakhstan travel guide. The page contains a hero, destinations, story, experiences, FAQ, navigation and footer.

## Assignment requirements covered

### Task 1 — Hand-written media queries
The **Destinations** section uses custom CSS only for its responsive layout.

- Mobile-first base: 1 card per row.
- `@media (min-width: 576px)`: 2 cards per row.
- `@media (min-width: 992px)`: 3 cards per row.
- The 992px breakpoint also changes the heading size and section spacing.
- No Bootstrap grid classes are used in this section.
- No fixed card widths or absolute positioning are used for the layout.

### Task 2 — Bootstrap
The rest of the page uses Bootstrap 5.3.

- Responsive navbar with collapse menu.
- Bootstrap `container`, `row`, `col-*` and breakpoints.
- `order-*` for the Story section.
- Bootstrap utility classes such as `d-none`, `d-lg-flex`, `d-lg-none`, `d-flex`, `text-secondary`, `ms-auto`, `py-*`, `mt-*`.
- Responsive experience cards: 1 / 2 / 3 columns.
- Bootstrap Accordion component.
- No floats or absolute positioning are used for the Bootstrap page layout.

## Files

- `index.html` — page structure and Bootstrap integration.
- `style.css` — custom CSS and Task 1 media queries.
- `README.md` — project information.

## Run

Open `index.html` in a browser. An internet connection is needed for Bootstrap 5.3 CDN assets.
